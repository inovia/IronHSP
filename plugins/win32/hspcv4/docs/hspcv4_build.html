hspcv4 ビルド手順

hspcv4 は OpenCV 4.x の機能を HSP から利用するためのプラグインです。 OpenCV 本体は配布リポジトリに含まれず、ビルドバッチが実行時に GitHub から自動ダウンロードします。本書はビルド手順と内部の動作を 記した開発者向けドキュメントです。

1. 必要な環境

  • Windows 10 (build 17063+) 以降 — curl と tar/PowerShell Expand-Archive が標準搭載
  • Visual Studio 2022 Community 以上
    • ワークロード: 「C++ によるデスクトップ開発」
    • 個別コンポーネント: 「Windows 用 C++ CMake ツール」
  • インターネット接続 (初回のみ、OpenCV ソース取得のため)
  • 空きディスク容量: 約 8 GB (ソース ~1GB、Debug 用中間生成物含めると x86/x64 合計でこのくらい)
Visual Studio のインストールパスは vswhere.exe で自動検出されます。 標準的な Community 以上なら追加設定は不要です。

2. クイックスタート

最短ルート:

cd plugins\win32\hspcv4\build
build_all.bat

これだけで以下が順に実行されます:

  1. setup_opencv.bat — OpenCV 4.12.0 の zip を curl で取得し、third_party\opencv-4.12.0\ に展開
  2. build_opencv_64.bat — x64 版を cmake + msbuild で静的ビルド
  3. build_opencv_32.bat — Win32 版を同様にビルド

初回は 30〜60 分程度かかります。2 回目以降は成果物が残っていればスキップされます。

3. ディレクトリ構成

plugins\win32\hspcv4\

├─ build\
│  ├─ setup_opencv.bat         OpenCV ソース DL + 展開 (冪等)

│  ├─ build_opencv_64.bat      x64 ビルドドライバ
│  ├─ build_all.bat            上記 3 つを順に実行
│  ├─ _build_opencv_common.bat 内部用 (cmake/msbuild 呼び出し本体)
│  ├─ opencv_build_32\         [git 管理外] cmake 中間生成物
│  ├─ opencv_build_64\
│  ├─ opencv_install_32\       [git 管理外] 静的ライブラリ出力
│  └─ opencv_install_64\
├─ docs\
│  └─ hspcv4_build.html        本ドキュメント
├─ src\                        hspcv4 本体 (Phase 1 以降)

└─ third_party\                [git 管理外]

   └─ opencv-4.12.0\           展開されたソース

4. CMake 設定の要点

_build_opencv_common.bat から呼び出される cmake は次の主要オプションを指定しています:

オプション値意味
BUILD_SHARED_LIBSOFF静的ライブラリとしてビルド
BUILD_WITH_STATIC_CRTOFFCRT は /MD (動的) を使用。hspcv4.dll 側の CRT と一致させる
BUILD_opencv_worldON全モジュールを 1 本の opencv_world4120.lib に統合
BUILD_TESTS / BUILD_PERF_TESTS / BUILD_EXAMPLESOFFビルド時間短縮
BUILD_opencv_python3 / BUILD_opencv_java / BUILD_opencv_jsOFF不要なバインディングを除外
WITH_CUDAOFFCUDA を要求しない
WITH_IPPONIntel IPP による高速化を有効
WITH_OPENCLONOpenCL 対応
WITH_FFMPEG / WITH_MSMF / WITH_DSHOWON動画・カメラ入力の主要経路を全部有効
CRT の一致: OpenCV は /MD (動的 CRT) でビルドされます。 hspcv4.dll 側も必ず /MD を使ってください。混在すると LNK2038: 'RuntimeLibrary' の不一致が検出されました が出ます。

5. 出力物

ビルドが成功すると以下に静的ライブラリが配置されます:

build\opencv_install_64\x64\vc17\staticlib\opencv_world4120.lib
build\opencv_install_32\x86\vc17\staticlib\opencv_world4120.lib

ヘッダは opencv_install_XX\include\opencv2\ 以下に。 hspcv4 本体の Visual Studio プロジェクトはこの install ディレクトリを include / lib パスとして参照します (Phase 1 で追加)。

6. 再ビルド・クリーンビルド

ビルドドライバは冪等です。次のルールで動作します:

  • opencv_install_XX\...\opencv_world4120.lib が存在すれば、そのアーキテクチャはスキップ
  • クリーンビルドしたい場合は、対応する opencv_build_XX と opencv_install_XX を削除してから再実行
rmdir /s /q build\opencv_build_64 build\opencv_install_64
build\build_opencv_64.bat

7. OpenCV ソースだけ更新したい

rmdir /s /q third_party
build\setup_opencv.bat

ZIP が third_party に残っていると再 DL は行われません。 完全に再 DL するには third_party\opencv-4.12.0.zip も削除してください。

8. トラブルシューティング

curl / tar が見つからない
Windows 10 build 17063 未満の場合は標準添付がありません。Windows を更新するか、Git for Windows などで別途導入してください。
vswhere.exe が見つからない
Visual Studio 2017 以降のインストーラがセットアップする共通コンポーネントです。VS2022 を正規の手順でインストールすれば存在します。
cmake.exe が見つからない
VS インストーラで「Windows 用 C++ CMake ツール」をチェックし直してください。
ビルド中にメモリ不足
-maxCpuCount を -maxCpuCount:2 のように明示すると並列数を抑えられます (_build_opencv_common.bat 内)。
ZIP 展開に失敗する
ウイルス対策ソフトが展開をブロックしていないか確認してください。third_party\ を除外対象に追加すると改善します。

9. オプション: FFmpeg 対応 (動画コーデック拡張)

既定のビルドは自己完結性を優先して FFmpeg を含めていません。 そのため cv4_writer_open / cv::VideoWriter で使える コーデックは Windows 標準の CV_IMAGES / DSHOW / MSMF 系バックエンドに限定されます。 MJPG / H264 / MP4 などを動画として書き出したい場合は、以下の手順で FFmpeg 対応を有効にしてください。

9.1 環境変数を指定してビルド

set HSPCV4_WITH_FFMPEG=1
build_all.bat

HSPCV4_WITH_FFMPEG=1 を設定すると、内部の _build_opencv_common.bat が cmake に -DWITH_FFMPEG=ON を渡します。これにより OpenCV は cmake configure 中に opencv_videoio_ffmpeg4120_64.dll (アーキに応じて 32/64bit の一方) を GitHub から自動ダウンロード して opencv_install_XX/x64/vc17/bin/ に配置します。

9.2 実行時配置

FFmpeg 対応でビルドした場合、生成された opencv_videoio_ffmpeg*.dll を実行バイナリ (hsp3.exe や EXE 化したゲーム) と同じディレクトリに配置する 必要があります。見つからない場合 cv::VideoCapture::open が 動画ファイル読込に失敗します (カメラ読込や画像書き出しは影響を受けません)。

FFmpeg DLL は OpenCV のビルド時に GitHub Releases から配信される、 OpenCV 用のアグリゲート ビルドです。ライセンスは LGPL-2.1+ で、 Windows 上のみで使えます。商用配布に含める際はライセンス条項を 確認してください。

9.3 既定に戻す

set HSPCV4_WITH_FFMPEG=
rmdir /s /q build\opencv_build_32 build\opencv_install_32
rmdir /s /q build\opencv_build_64 build\opencv_install_64
build_all.bat

10. バージョン情報

本ビルドシステムが取得する OpenCV のバージョンは setup_opencv.bat 内の OPENCV_VERSION 変数で管理されています。 上げる場合は以下を変更してください:

set "OPENCV_VERSION=4.12.0"

同時に _build_opencv_common.bat のスキップ判定で使っている opencv_world4120.lib のファイル名 (4120 部分) も 新バージョンに合わせて更新する必要があります。
