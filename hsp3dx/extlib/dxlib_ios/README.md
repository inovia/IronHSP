# hsp3dx/extlib/dxlib_ios

**DxLib iOS 版 SDK の配置先。Phase 3 (iOS 版 hsp3dx) で使う**。SDK 本体はリポジトリに含まれない (`.gitignore` で除外)。

## 取得手順

1. 公式ダウンロードページ https://dxlib.xsrv.jp/dxdload.html にアクセス
2. **iOS 用パッケージ** をダウンロード
   - 直リンク (Ver3.24f 時点): https://dxlib.xsrv.jp/DxLib/DxLib_iOS3_24f.zip
   - サイズ: 約 78 MB
3. zip を展開して、本ディレクトリに配置 (具体的な構造は zip の `README.txt` に従う)

## 使い方 (Phase 3 予定)

Xcode プロジェクトから静的ライブラリ (`.a`) をリンクする形で使う。詳細は Phase 3 で `hsp3dx/ios/` のテンプレを作成する際に文書化予定。

## 現状 (Phase 1.0)

本ディレクトリは Phase 3 までプレースホルダ。配置作業は iOS 版着手時に行えば OK。
