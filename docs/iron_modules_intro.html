IronHSP Simple モジュール集 (iron_*.hsp) は、HTTP 通信、JSON、AI API、音声認識、DB、アーカイブ、Webcam、MCP、暗号化、正規表現、グラフ描画など、 モダンな機能を HSP らしい 1～2 行のシンプルな書き方で使えるようにまとめたラッパ群です。 全部 #include するだけで使えます。

例 1: 天気予報を取得して JSON パース

#include "iron_http.hsp"
#include "iron_json.hsp"

    url = "https://api.open-meteo.com/v1/forecast?latitude=35.68&longitude=139.69&current=temperature_2m"
    http_get url, body
    if stat = 200 {
        hid = json_load(body)
        mes "東京の現在気温: " + json_dbl(hid, "current.temperature_2m") + " ℃"
        json_release hid
    }
    stop

インストール

IronHSP 2026 を clone すれば、全部 package/win32/common/iron_*.hsp として配布されています。HSP スクリプト側は:

#include "iron_http.hsp"
#include "iron_json.hsp"
#include "iron_ai.hsp"
; ... 必要なモジュールだけ

依存 DLL (hspjson.dll, hspmfcam.dll 等) は plugins/win32/hsp*/Release/ にビルド出力があるので、それらを HSP 実行ファイルと同じディレクトリにコピーしてください。

設計方針

  • 戻り値は HSP 慣習通り: 文字列は refstr もしくは出力 var 引数、整数は stat、実数は refdval
  • 初期化レス: 各 API は内部で「初回呼び出し時にのみ初期化」する自動セットアップ
  • 1 行で書けることが目玉: 例えば http_get url, body 1 行で HTTP 取得が完結する
  • SJIS ベース: 日本語の取り扱いに HSP 標準の SJIS を使用

次のステップ

  • ヘルプファイル: 各モジュールに対応する package/hsphelp/iron_*.hs があり、HSP IDE で命令名にカーソルを合わせて F1 で日本語リファレンスが開きます
  • サンプル: package/win32/sample/iron/ にそれぞれのモジュールの動作サンプルがあります
  • 詳細仕様: docs/IronHSP_specification.html のセクション 17 で全機能を解説
  • API キー取得:
    • Groq (無料枠あり): console.groq.com
    • OpenAI: platform.openai.com
    • Anthropic: console.anthropic.com
    • Ollama (ローカル、無料): ollama.com

ライセンス

IronHSP 2026 は OpenHSP 3.8beta1 (BSD) をベースとした派生物で、追加分も BSD 扱いです。各 iron_* モジュールも BSD ライセンスで配布されます。サードパーティ DLL (miniz, SQLite, whisper.cpp, Vosk, PCRE2, libssh2, DuckDB 等) はそれぞれの配布元ライセンスに従います。
