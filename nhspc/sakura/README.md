# サクラエディタ用 NHSP 強調キーワード & ヘルプファイル

サクラエディタで NHSP (Net HSP / .nhsp ファイル) のシンタックスハイライトとキーワードヘルプを使えるようにする設定ファイルです。

## 仕様

- バージョン: 2026-04-13
- 対象言語: NHSP (Net HSP) 0.2 — HSP風文法の .NET コンパイラ言語
- 制作者: IronHSP project
- 参考資料: https://github.com/inovia/IronHSP

## ファイル構成

```
sakura/
├── nhsp.kwd              — 強調キーワード (制御構文 / 修飾子 / 型エイリアス)
├── nhsp_directives.kwd   — 強調キーワード (#assembly などのディレクティブ名)
├── nhsp.khp              — キーワードヘルプ (nhsp.kwd 用の説明)
├── nhsp_directives.khp   — キーワードヘルプ (ディレクティブ用の説明)
└── README.md             — このファイル
```

`nhsp.kwd` と `nhsp_directives.kwd` を別セットとして登録すると 2 色で色分けできます。
`.kwd` / `.khp` は **Shift-JIS (CP932) + CRLF** で保存されています (サクラエディタ標準形式)。

## 設定手順

### 1. キーワードセットを登録

1. サクラエディタのメニューから `[設定] → [共通設定]` を開き、`[強調キーワード]` タブをクリック。
2. `[セット追加]` をクリックし、セット名を入力 (例: `NHSP`)。
3. `[インポート]` をクリックし、`nhsp.kwd` を選択。`[英大文字小文字区別]` をチェックして `[OK]`。
4. 同様に `[セット追加]` で `NHSP directives` を作成し、`nhsp_directives.kwd` をインポート。
5. `[OK]` で共通設定を閉じる。

### 2. タイプ別設定 (.nhsp 拡張子の関連付け)

1. `[設定] → [タイプ別設定一覧]` を開き、空いている設定 (例: 設定 17) を選択 → `[設定変更]`。空きがなければ `[追加]` で新しい設定を作成。
2. `[スクリーン]` タブ
   - 設定の名前: `NHSP`
   - ファイル拡張子: `nhsp`
3. `[カラー]` タブ
   - `[強調キーワード1]`: `NHSP` を選択
   - `[強調キーワードの 2〜10]` ボタン → 2 番目に `NHSP directives` を選択
   - `[コメントスタイル・行型]` の欄に `;` を入力 (NHSP は `;` 行コメントを使う)
   - `[行コメント2]` に `//` を入力 (NHSP は `//` 行コメントも使える)
   - 必要なら `[シングルクォーテーション]` / `[ダブルクォーテーション]` をチェック (`"..."` 文字列の色付け)
4. `[支援]` タブ
   - `[入力補完機能]` の `[強調キーワード]` をチェックすると `Ctrl+スペース` で補完候補が出ます。
5. `[キーワードヘルプ]` タブ
   1. `[キーワードヘルプ機能を使う]` をチェック。
   2. `[辞書ファイル]` の `[...]` をクリックし `nhsp.khp` を選択 → `[挿入]`。
   3. 同様に `nhsp_directives.khp` も追加。
6. `[OK]` で保存。

## 入力補完機能

`.nhsp` ファイルを開いた状態で、例えば `cl` と入力した直後にカーソルがある状態で `Ctrl+スペース` を押すと、`cl` で始まるキーワード一覧 (`class`, `const` など) がポップアップします。

## ヘルプ機能

`.nhsp` ファイルを開いた状態で、キーワードを範囲選択してその上にマウスカーソルを重ねると説明がツールチップとして表示されます。例えば `#class` を選択すれば「クラス定義開始。#endclass で終了」と表示されます。

## ディレクティブの色分けを精密にしたい場合

NHSP ディレクティブは必ず `#` 始まりですが、サクラエディタはデフォルトでは `#` を単語境界として扱うため、`#class` の `#` と `class` を別々のトークンとして見ます。両者を一つの単語として強調したい場合は:

`[タイプ別設定 → カラー → [単語に含める文字]` に `#` を追加してください。すると `#class` 全体が 1 つのトークンとしてマッチし、`nhsp_directives.kwd` のエントリ (`#` を含めて書いてください) と一致するようになります。

ただしこの設定は他の言語にも影響することがあるので、`#` を含めない素のままでも実用上は問題ありません (`#` は記号として描画され `class` の部分だけがディレクティブとして強調されます)。

## ファイルを更新したら

`.kwd` や `.khp` を上書きした場合、サクラエディタを再起動するか、`[強調キーワード]` の対象セットで `[インポート]` し直してください。ファイルの**置き場所**を変えた場合は再設定が必要です。
