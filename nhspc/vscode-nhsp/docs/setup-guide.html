1. 必要なもの

ソフトウェアバージョン入手先
Visual Studio Code1.75 以上https://code.visualstudio.com/
Node.js16 以上 (vsix パッケージ作成時のみ)https://nodejs.org/
.NET Framework 4.8ランタイムWindows 10 には標準搭載
nhspc.exe最新版ビルド済み、またはソースからビルド
Node.js は拡張を .vsix パッケージ化する場合のみ必要です。 フォルダコピーでインストールする場合は不要です。

2. 拡張のインストール

4つの方法があります。簡単な順に説明します。

方法 A: install.bat を実行（最も簡単・推奨）

install.bat をダブルクリック

vscode-nhsp フォルダ内の install.bat をダブルクリックするだけです。

nhspc\vscode-nhsp\install.bat

バッチファイルが自動で以下を行います:

  • VS Code の存在確認
  • 既存インストールの削除 (更新時)
  • 拡張ファイルを正しいディレクトリにコピー
  • nhspc.exe の自動検出
VS Code を再起動

VS Code を完全に閉じて再度開くと、拡張が読み込まれます。

確認: .nhsp ファイルを開く

任意の .nhsp ファイルを開いて、シンタックスハイライトが適用されることを確認します。 右下のステータスバーに「NHSP」と表示されれば成功です。

アンインストールする場合は uninstall.bat をダブルクリックしてください。

方法 B: 手動でフォルダコピー

拡張フォルダを VS Code の拡張ディレクトリにコピー

vscode-nhsp フォルダの中身を以下にコピーします:

%USERPROFILE%\.vscode\extensions\nhsp-language-0.1.0\

コマンドプロンプトの場合:

xcopy /E /I "nhspc\vscode-nhsp" "%USERPROFILE%\.vscode\extensions\nhsp-language-0.1.0"

コピー後、VS Code を再起動してください。

方法 C: code コマンドでインストール

VS Code の code コマンドを使用 
code --install-extension "nhspc\vscode-nhsp"

方法 D: .vsix パッケージを作成してインストール

配布用にパッケージ化する場合はこちら。Node.js が必要です。

vsce (VS Code Extension Manager) をインストール 
npm install -g @vscode/vsce
パッケージ作成 
cd nhspc\vscode-nhsp
vsce package

nhsp-language-0.1.0.vsix が生成されます。

vsix をインストール 
code --install-extension nhsp-language-0.1.0.vsix

または VS Code の拡張パネルで「...」メニュー →「VSIX からインストール」を選択してファイルを指定。

.vsix ファイルは他の PC に配布できます。受け取った側は上の code --install-extension コマンドか、VS Code の拡張パネルからインストールできます。

3. 設定

nhspc.exe のパス設定

拡張はコンパイル時に nhspc.exe を使います。以下の順序で自動検出します:

  1. 設定 nhsp.compilerPath で指定されたパス
  2. ワークスペースフォルダ直下の nhspc.exe
  3. nhspc/nhspc/bin/Debug/nhspc.exe (ソースからビルドした場合)

自動検出できない場合は、VS Code の設定で明示的に指定してください:

// settings.json
{
  "nhsp.compilerPath": "C:\\path\\to\\nhspc\\nhspc\\bin\\Debug\\nhspc.exe"
}

設定の開き方: Ctrl+, → 検索欄に「nhsp」と入力

出力ディレクトリ設定（任意）

{
  "nhsp.outputDirectory": "C:\\output\\path"
}

省略するとソースファイルと同じディレクトリに出力されます。

4. 基本的な使い方

新しいファイルを作る

.nhsp ファイルを作成

Ctrl+N で新規ファイル → Ctrl+S で hello.nhsp として保存

コードを書く
#assembly "Hello", exe

#class public Program
  #func public static void Main
    print "Hello NHSP!"
  #endfunc
#endclass

#main
  Program.Main()
#endmain
コンパイル

F5 を押すとコンパイルされます。

  • #main があれば EXE が生成されます
  • #main がなければ DLL が生成されます
実行（EXE の場合）

F6 でコンパイル＆実行。ターミナルに結果が表示されます。

DLL を作る場合

#assembly "MyLibrary"

#class public Calculator
  #func public static int Add, int a, int b
    return a + b
  #endfunc
#endclass

F5 で MyLibrary.dll が生成されます。#main がないので自動的に DLL になります。

強制的に DLL にしたい場合は、コマンドパレット (Ctrl+Shift+P) → 「NHSP: Compile as DLL」を選択。

7. 入力補完の使い方

# ディレクティブ補完

# を入力すると全ディレクティブの候補が表示されます。

# と入力 → 候補:
  #assembly
  #class
  #func
  #field
  #struct
  ...

メンバー補完

変数名の後に . を入力すると、型に応じたメンバー候補が表示されます。

string s = "hello"
s. と入力 → 候補:
  Length    // int (文字列の長さ)
  ToUpper() // string (大文字に変換)
  Contains() // bool (文字列を含むか)
  Substring() // string (部分文字列)
  Replace()  // string (文字列置換)
  ...

ブロック自動閉じ

#func 等のブロック開始ディレクティブを書いて Enter を押すと、終了ディレクティブが自動挿入されます。

#func public int Add, int a, int b と書いて Enter →

#func public int Add, int a, int b
  |               ← カーソルはここ
#endfunc       ← 自動挿入

スニペット

キーワードを入力して Tab を押すとテンプレートが展開されます。

for + Tab →

for i = 0 to 10
  |
next

; ハイライト部分は Tab で次のプレースホルダに移動

8. トラブルシューティング

「nhspc.exe not found」と表示される
→ 設定で nhsp.compilerPath に nhspc.exe のフルパスを指定してください。
"nhsp.compilerPath": "C:\\IronHSP\\nhspc\\nhspc\\bin\\Debug\\nhspc.exe"
シンタックスハイライトが効かない
→ ファイルの拡張子が .nhsp であることを確認。
→ VS Code 右下のステータスバーに「NHSP」と表示されているか確認。
→ 表示されていなければ、クリックして「NHSP」を選択。
コンパイルエラーが波線で表示されない
→ ファイルを保存 (Ctrl+S) すると自動コンパイルが走り、エラーが表示されます。
→ 「問題」パネル (Ctrl+Shift+M) でエラー一覧を確認。
拡張が読み込まれない
→ Ctrl+Shift+P →「Developer: Reload Window」で再読み込み。
→ 拡張フォルダが正しい場所にコピーされているか確認: 
%USERPROFILE%\.vscode\extensions\nhsp-language-0.1.0\
  ├── package.json
  ├── language-configuration.json
  ├── syntaxes\nhsp.tmLanguage.json
  ├── snippets\nhsp.json
  └── src\extension.js

9. スタンドアロンエディタ

VS Code を使わない場合は、付属のスタンドアロンエディタ NhspEditor.exe も利用できます。

ビルド方法

cd nhspc
dotnet build NhspEditor\NhspEditor.csproj -c Release

NhspEditor\bin\Release\NhspEditor.exe が生成されます。

ショートカット

キー機能
F5コンパイル (EXE/DLL 自動判定)
F7DLL としてビルド
Ctrl+F5デバッグ情報付きコンパイル
F6コンパイル＆実行
Ctrl+N新規ファイル
Ctrl+Oファイルを開く
Ctrl+S上書き保存
NhspEditor.exe は NhspCompiler.Core.dll を直接参照するため、nhspc.exe のパス設定は不要です。 エラー一覧のダブルクリックでエラー箇所にジャンプできます。
